📊 状态反馈 ​

查看完整来源文档

状态发布频率由每只手臂状态节点的 rate_hz 参数设置，当前部署值为 20 Hz； 发布器使用队列深度 10。

5.1 joint_states ​

字段当前内容
header.stamp驱动发布时间
name对应手臂的 7 个标准关节名
positionSDK jointPos()，7 个关节角，rad
velocity当前未填写
effort当前未填写

查看数据：

bash
ros2 topic echo /left_arm/joint_states

5.2 tcp_pose ​

类型为 geometry_msgs/msg/PoseStamped：

  • position：TCP 的 XYZ，单位 m。
  • orientation：驱动把 SDK 位姿转换成四元数。
  • header.frame_id：对应手臂配置的外部参考坐标系名称。
bash
ros2 topic echo /right_arm/tcp_pose

5.3 jacobian ​

类型为 std_msgs/msg/Float64MultiArray。data 是按行优先展开的 6 x 7 矩阵：

text
行：vx, vy, vz, wx, wy, wz
列：joint_1, joint_2, ..., joint_7
索引：data[row * 7 + column]

layout：

维度labelsizestride
0twist642
1joint77

publish_jacobian=false 时不存在对应发布器。启用后若没有订阅者，驱动跳过 Jacobian 计算。

bash
ros2 topic echo /left_arm/jacobian --once
